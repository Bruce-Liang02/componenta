# Componenta 组件形态页面模板规范

> 版本：v1.0
> 状态：已冻结（2026-09-13）

---

## 一、站点结构

```
/catalog                    → 总览目录页（单页全量矩阵）
/catalog/v/:id              → 形态详情页（一形态一页）
/catalog/demo/:id           → 形态交互演示（全屏模式）
/catalog/compare/:ids       → 形态横向对比页
/catalog/guide              → 选型向导
/catalog/cheatsheet         → 编号速查表
```

路由前缀 `/catalog`，集成到 web-admin 的 SystemLayout 中。

| 操作                      | 行为                             |
| ------------------------- | -------------------------------- |
| 输入编号（如 `PT001`）    | 精确匹配，滚动定位并高亮该卡片   |
| 输入关键词（如「审批」）  | 模糊搜索，过滤卡片               |

| 点击类别标题「展开/收起」 | 折叠/展开该类别下的所有卡片      |

| 悬浮卡片                  | 显示「复制编号」「加入对比」按钮 |
| URL 锚点（`/#PT001`）     | 滚动定位到该卡片                 |

## 七、响应式断点

| 断点 | 宽度     | 卡片列数 | 侧边导航             |
| ---- | -------- | -------- | -------------------- |
| xs   | < 576px  | 1 列     | 隐藏（改为顶部下拉） |
| sm   | ≥ 576px  | 2 列     | 隐藏                 |
| md   | ≥ 768px  | 3 列     | 显示                 |
| lg   | ≥ 992px  | 4 列     | 显示                 |
| xl   | ≥ 1200px | 5 列     | 显示                 |
| xxl  | ≥ 1600px | 6 列     | 显示                 |
